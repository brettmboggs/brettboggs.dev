# The editor

Every word on the site can be changed at <https://brettboggs.dev/edit/>. It is
Sveltia CMS: it reads and writes the files in this repo through GitHub, every
save is a commit to `main`, and the deploy workflow publishes it in about a
minute.

## Who can sign in

Only GitHub accounts with write access to `brettmboggs/brettboggs.dev`, which
is Brett alone. The editor page itself is public and grants nothing; GitHub
refuses a save from anyone else.

## Where the words live

| What | File | Editor section |
| --- | --- | --- |
| Page copy, one file per page | `src/data/copy/<page>.json` | Pages, Work pages, Lab pages, Slumbio |
| Work entries (titles, descriptions, dates, bodies) | `src/content/work/*.md` | Work entries |
| Resume, also served as `/resume.json` | `public/resume.json` | Resume |
| Uploaded images | `public/uploads/` | Media |

Fields with links or emphasis are Markdown. Everything else is plain text.
Some lists carry a note like "keep 5": a film or viewer on that page counts
on that many items, so edit the words and leave the count.

Signed in, every page shows an **Edit** button in the bottom-left corner that
opens that page's form. Visitors never see it.

Still in code: text generated by scripts (the 404 game's messages, the
keepsake's seed line, the checkout button states, the drafting film's drawing
labels), date formatting, and the navigation labels in `src/layouts/Base.astro`.
`public/llms.txt` is plain text and is edited directly.

## Signing in

**Access token (works now, no servers).**
1. <https://github.com/settings/personal-access-tokens/new>: name it
   `brettboggs.dev editor`, repository access **Only select repositories** →
   `brettboggs.dev`, permission **Contents: Read and write**, nothing else.
2. Open `/edit/` → **Sign In Using Access Token** → paste. The browser keeps it.

**Sign in with GitHub (one click).** Needs the small Worker in
`tools/edit-auth/`, because GitHub's OAuth flow needs a server to swap a code
for a token.
1. <https://github.com/settings/developers> → New OAuth App. Name
   `brettboggs.dev editor`, homepage `https://brettboggs.dev`, callback
   `https://brettboggs-edit-auth.<subdomain>.workers.dev/callback`.
   Generate a client secret.
2. Put the client id in `tools/edit-auth/wrangler.toml` as `GITHUB_CLIENT_ID`.
3. From `tools/edit-auth/`, signed in to the personal Cloudflare account (the
   one with `brettboggs-store`): `npx wrangler deploy`, then
   `npx wrangler secret put GITHUB_CLIENT_SECRET` and paste the secret.
4. Add `base_url: https://brettboggs-edit-auth.<subdomain>.workers.dev` under
   `backend:` in `public/edit/config.yml` and push.

If the secret ever leaks: generate a new one in the OAuth app, delete the old,
and `wrangler secret put` it again. Nothing else changes.

## Editing without signing in

`npm run dev`, open <http://localhost:4321/edit/> in Chrome or Edge, **Work
with Local Repository**, pick this folder. Saves land on disk; commit them.
